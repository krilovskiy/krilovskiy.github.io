## Условие задачи

Найдите максимальное значение в битоническом массиве. Такой массив сначала монотонно возрастает, затем монотонно убывает. В каждой части соседние элементы различны: `arr[i] != arr[i+1]`.

Примеры также допускают полностью возрастающий или полностью убывающий массив.

**Пример 1:**

```text
Вход: [1, 3, 8, 12, 4, 2]
Выход: 12
```

Максимальное число — `12`.

**Пример 2:**

```text
Вход: [3, 8, 3, 1]
Выход: 8
```

**Пример 3:**

```text
Вход: [1, 3, 8, 12]
Выход: 12
```

**Пример 4:**

```text
Вход: [10, 9, 8]
Выход: 10
```

## Решение

У битонического массива две упорядоченные части: возрастающая и убывающая. Применим модификацию бинарного поиска. На каждом шаге сравниваем `arr[mid]` и `arr[mid+1]`:

1. Если `arr[mid] > arr[mid+1]`, мы на убывающей части. Максимум может находиться на позиции `mid` или левее, поэтому устанавливаем `end = mid`.
2. Если `arr[mid] <= arr[mid+1]`, мы на возрастающей части. Максимум находится правее, поэтому устанавливаем `start = mid+1`.

Цикл продолжается, пока `start < end`. После его завершения оба индекса указывают на максимум. Пока цикл работает, `mid < end`, поэтому элемент `mid+1` находится внутри массива.

## Код

Для поиска значения максимума массив должен быть непустым.

{% raw %}
```go
package main

import "fmt"

func findMax(arr []int) int {
	if len(arr) == 0 {
		panic("массив должен быть непустым")
	}
	start, end := 0, len(arr)-1
	for start < end {
		mid := start + (end-start)/2
		if arr[mid] > arr[mid+1] {
			end = mid
		} else {
			start = mid + 1
		}
	}
	return arr[start]
}
func main() {
	fmt.Println("Максимум:", findMax([]int{1, 3, 8, 12, 4, 2}))
	fmt.Println("Максимум:", findMax([]int{3, 8, 3, 1}))
	fmt.Println("Максимум:", findMax([]int{1, 3, 8, 12}))
	fmt.Println("Максимум:", findMax([]int{10, 9, 8}))
}
```
{% endraw %}

**Вывод:**

```text
Максимум: 12
Максимум: 8
Максимум: 12
Максимум: 10
```

## Временная сложность

На каждом шаге диапазон поиска уменьшается вдвое. Временная сложность — $$O(\log N)$$, где $$N$$ — число элементов массива.

## Пространственная сложность

Алгоритм использует постоянную дополнительную память — $$O(1)$$.

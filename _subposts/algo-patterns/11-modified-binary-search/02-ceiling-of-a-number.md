## Условие задачи

Дан массив чисел, отсортированный по возрастанию. Найдите верхнюю границу числа `key` — наименьший элемент массива, который больше или равен `key` (ceiling).

Верните индекс этого элемента. Если верхней границы нет, верните `-1`.

**Пример 1:**

```text
Вход: [4, 6, 10], key = 6
Выход: 1
```

Наименьшее число не меньше `6` — само `6` с индексом `1`.

**Пример 2:**

```text
Вход: [1, 3, 8, 10, 15], key = 12
Выход: 4
```

Наименьшее число не меньше `12` — `15` с индексом `4`.

**Пример 3:**

```text
Вход: [4, 6, 10], key = 17
Выход: -1
```

Чисел не меньше `17` в массиве нет.

**Пример 4:**

```text
Вход: [4, 6, 10], key = -1
Выход: 0
```

Наименьшее число не меньше `-1` — `4` с индексом `0`.

## Решение

Задача следует паттерну бинарного поиска. Как и в первой задаче главы, ищем `key` в массиве по возрастанию.

Если число найдено, его индекс и будет ответом. Если оно отсутствует, после выхода из цикла `start` указывает на наименьший элемент больше `key`.

Это происходит потому, что при `key > arr[mid]` передвигаем `start` вправо, а при `key < arr[mid]` передвигаем `end` влево. После завершения поиска `start == end+1`.

Для `key=12`:

[![Поиск верхней границы числа 12: start останавливается на элементе 15](/assets/img/posts/2027-02-01-algo-patterns-modified-binary-search/ceiling-search-steps.svg)](/assets/img/posts/2027-02-01-algo-patterns-modified-binary-search/ceiling-search-steps.svg)

Перед поиском проверяем, не больше ли `key` самого большого элемента массива. Если больше, верхней границы нет и можно сразу вернуть `-1`.

## Код

{% raw %}
```go
package main

import "fmt"

func searchCeilingOfANumber(arr []int, key int) int {
	n := len(arr)
	if n == 0 || key > arr[n-1] {
		return -1
	}
	start, end := 0, n-1
	for start <= end {
		mid := start + (end-start)/2
		if key < arr[mid] {
			end = mid - 1
		} else if key > arr[mid] {
			start = mid + 1
		} else {
			return mid
		}
	}
	return start
}
func main() {
	fmt.Println("Индекс верхней границы:", searchCeilingOfANumber([]int{4, 6, 10}, 6))
	fmt.Println("Индекс верхней границы:", searchCeilingOfANumber([]int{1, 3, 8, 10, 15}, 12))
	fmt.Println("Индекс верхней границы:", searchCeilingOfANumber([]int{4, 6, 10}, 17))
	fmt.Println("Индекс верхней границы:", searchCeilingOfANumber([]int{4, 6, 10}, -1))
}
```
{% endraw %}

**Вывод:**

```text
Индекс верхней границы: 1
Индекс верхней границы: 4
Индекс верхней границы: -1
Индекс верхней границы: 0
```

## Временная сложность

На каждом шаге диапазон поиска уменьшается вдвое. Временная сложность — $$O(\log N)$$, где $$N$$ — число элементов массива.

## Пространственная сложность

Алгоритм использует постоянную дополнительную память — $$O(1)$$.

## Вариации задачи

### Нижняя граница числа

В оригинале приведена похожая задача: найдите нижнюю границу `key` (floor) — наибольший элемент массива, который меньше или равен `key`. Верните его индекс, а если такого элемента нет — `-1`.

**Пример 1:**

```text
Вход: [4, 6, 10], key = 6
Выход: 1
```

Наибольшее число не больше `6` — `6` с индексом `1`.

**Пример 2:**

```text
Вход: [1, 3, 8, 10, 15], key = 12
Выход: 3
```

Наибольшее число не больше `12` — `10` с индексом `3`.

**Пример 3:**

```text
Вход: [4, 6, 10], key = 17
Выход: 2
```

Наибольшее число не больше `17` — `10` с индексом `2`.

**Пример 4:**

```text
Вход: [4, 6, 10], key = -1
Выход: -1
```

Чисел не больше `-1` в массиве нет.

### Решение

Алгоритм почти не меняется. В начале проверяем, не меньше ли `key` первого элемента. При точном совпадении возвращаем найденный индекс, а после неудачного поиска — `end`, который указывает на ближайшее меньшее число.

### Код

{% raw %}
```go
package main

import "fmt"

func searchFloorOfANumber(arr []int, key int) int {
	if len(arr) == 0 || key < arr[0] {
		return -1
	}
	start, end := 0, len(arr)-1
	for start <= end {
		mid := start + (end-start)/2
		if key < arr[mid] {
			end = mid - 1
		} else if key > arr[mid] {
			start = mid + 1
		} else {
			return mid
		}
	}
	return end
}
func main() {
	fmt.Println("Индекс нижней границы:", searchFloorOfANumber([]int{4, 6, 10}, 6))
	fmt.Println("Индекс нижней границы:", searchFloorOfANumber([]int{1, 3, 8, 10, 15}, 12))
	fmt.Println("Индекс нижней границы:", searchFloorOfANumber([]int{4, 6, 10}, 17))
	fmt.Println("Индекс нижней границы:", searchFloorOfANumber([]int{4, 6, 10}, -1))
}
```
{% endraw %}

**Вывод:**

```text
Индекс нижней границы: 1
Индекс нижней границы: 3
Индекс нижней границы: 2
Индекс нижней границы: -1
```

### Временная сложность

Диапазон поиска уменьшается вдвое на каждом шаге: $$O(\log N)$$.

### Пространственная сложность

Дополнительная память — $$O(1)$$.

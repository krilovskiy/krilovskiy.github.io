## Условие задачи

Дан массив строчных букв, отсортированный по возрастанию. Найдите наименьшую букву массива, которая больше заданной буквы `key`.

Массив считается циклическим: после последней буквы идёт первая. Если большей буквы нет, верните первую букву массива.

**Пример 1:**

```text
Вход: ['a', 'c', 'f', 'h'], key = 'f'
Выход: 'h'
```

Наименьшая буква больше `f` — `h`.

**Пример 2:**

```text
Вход: ['a', 'c', 'f', 'h'], key = 'b'
Выход: 'c'
```

Наименьшая буква больше `b` — `c`.

**Пример 3:**

```text
Вход: ['a', 'c', 'f', 'h'], key = 'm'
Выход: 'a'
```

Большей буквы нет, поэтому возвращаемся к началу массива.

**Пример 4:**

```text
Вход: ['a', 'c', 'f', 'h'], key = 'h'
Выход: 'a'
```

После последней буквы `h` идёт первая буква `a`.

## Решение

Используем модификацию бинарного поиска из задачи «Верхняя граница числа». Есть два отличия:

1. Если `key` меньше первой буквы или больше последней, ответ — первая буква.
2. Искомая буква должна быть строго больше `key`. Поэтому при равенстве не возвращаем `mid`, а продолжаем справа: `start = mid+1`.

После выхода из цикла возвращаем `letters[start % n]`. Если `key` совпадает с последней буквой, `start` станет равен длине массива `n`, а остаток от деления вернёт индекс `0`.

## Код

В Go буквы представлены рунами. Массив должен содержать хотя бы одну букву, иначе следующую букву выбрать невозможно.

{% raw %}
```go
package main

import "fmt"

func searchNextLetter(letters []rune, key rune) rune {
	n := len(letters)
	if n == 0 {
		panic("массив букв должен быть непустым")
	}
	if key < letters[0] || key > letters[n-1] {
		return letters[0]
	}
	start, end := 0, n-1
	for start <= end {
		mid := start + (end-start)/2
		if key < letters[mid] {
			end = mid - 1
		} else {
			start = mid + 1
		}
	}
	return letters[start%n]
}
func main() {
	letters := []rune{'a', 'c', 'f', 'h'}
	for _, key := range []rune{'f', 'b', 'm', 'h'} {
		fmt.Printf("Следующая буква для %c: %c\n", key, searchNextLetter(letters, key))
	}
}
```
{% endraw %}

**Вывод:**

```text
Следующая буква для f: h
Следующая буква для b: c
Следующая буква для m: a
Следующая буква для h: a
```

## Временная сложность

На каждом шаге диапазон поиска уменьшается вдвое. Временная сложность — $$O(\log N)$$, где $$N$$ — число элементов массива.

## Пространственная сложность

Алгоритм использует постоянную дополнительную память — $$O(1)$$.

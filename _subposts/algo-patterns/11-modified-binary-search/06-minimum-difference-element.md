## Условие задачи

Дан массив чисел, отсортированный по возрастанию. Найдите элемент, который имеет минимальную разницу с заданным числом `key`.

**Пример 1:**

```text
Вход: [4, 6, 10], key = 7
Выход: 6
```

Разница между `7` и `6` меньше, чем между `7` и любым другим числом массива.

**Пример 2:**

```text
Вход: [4, 6, 10], key = 4
Выход: 4
```

**Пример 3:**

```text
Вход: [1, 3, 8, 10, 15], key = 12
Выход: 10
```

**Пример 4:**

```text
Вход: [4, 6, 10], key = 17
Выход: 10
```

## Решение

Используем бинарный поиск из первой задачи главы.

Если `key` найден, возвращаем сам элемент: разница равна нулю. Если число отсутствует, после выхода из цикла `start` и `end` указывают на ближайшие числа справа и слева от него. Сравниваем `arr[start]-key` и `key-arr[end]`, возвращая число с меньшей разницей.

В исходном коде при равных разницах выбирается меньшее число — `arr[end]`.

Отдельно обрабатываем ключ за пределами значений массива: если он меньше первого элемента, возвращаем первый; если больше последнего — последний.

## Код

Массив должен быть непустым, чтобы в нём был элемент для ответа. Для сравнения неотрицательных расстояний используем `uint`: разница крайних значений `int` может не поместиться в `int`.

{% raw %}
```go
package main

import "fmt"

func searchMinDiffElement(arr []int, key int) int {
	if len(arr) == 0 {
		panic("массив должен быть непустым")
	}
	if key < arr[0] {
		return arr[0]
	}
	n := len(arr)
	if key > arr[n-1] {
		return arr[n-1]
	}
	start, end := 0, n-1
	for start <= end {
		mid := start + (end-start)/2
		if key < arr[mid] {
			end = mid - 1
		} else if key > arr[mid] {
			start = mid + 1
		} else {
			return arr[mid]
		}
	}
	// Разности неотрицательны; uint позволяет сравнить их без переполнения int.
	if uint(arr[start])-uint(key) < uint(key)-uint(arr[end]) {
		return arr[start]
	}
	return arr[end]
}
func main() {
	fmt.Println("Ближайшее число:", searchMinDiffElement([]int{4, 6, 10}, 7))
	fmt.Println("Ближайшее число:", searchMinDiffElement([]int{4, 6, 10}, 4))
	fmt.Println("Ближайшее число:", searchMinDiffElement([]int{1, 3, 8, 10, 15}, 12))
	fmt.Println("Ближайшее число:", searchMinDiffElement([]int{4, 6, 10}, 17))
}
```
{% endraw %}

**Вывод:**

```text
Ближайшее число: 6
Ближайшее число: 4
Ближайшее число: 10
Ближайшее число: 10
```

## Временная сложность

На каждом шаге диапазон поиска уменьшается вдвое. Временная сложность — $$O(\log N)$$, где $$N$$ — число элементов массива.

Алгоритм использует постоянную дополнительную память — $$O(1)$$.

## Условие задачи

Дано число $$n$$. Напишите функцию, которая возвращает количество структурно уникальных бинарных деревьев поиска (BST), содержащих значения от `1` до `n`.

**Пример 1:**

```text
Вход: n = 2
Выход: 2
```

Как мы видели в предыдущей задаче, значения `1` и `2` можно разместить в двух различных BST.

**Пример 2:**

```text
Вход: n = 3
Выход: 5
```

Для значений от `1` до `3` существует пять различных BST. В пояснении оригинала ошибочно указан диапазон до `5`; вход и результат относятся к `n=3`.

## Решение

Задача похожа на построение структурно уникальных BST. Перебираем числа от `1` до `n`, рассматривая каждое как корень, и делаем два рекурсивных вызова для подсчёта левых и правых поддеревьев.

Если корень равен `i`, слева находятся `i-1` значений, а справа — `n-i`. Любое левое поддерево можно совместить с любым правым, поэтому число вариантов для этого корня равно произведению двух счётчиков. Складываем произведения для всех корней.

Для нуля или одного узла возвращаем `1`: пустое поддерево — один допустимый вариант при комбинировании с другим поддеревом.

## Код

{% raw %}
```go
package main

import "fmt"

func countTrees(n int) int {
	if n <= 1 {
		return 1
	}
	count := 0
	for i := 1; i <= n; i++ {
		countOfLeftSubtrees := countTrees(i - 1)
		countOfRightSubtrees := countTrees(n - i)
		count += countOfLeftSubtrees * countOfRightSubtrees
	}
	return count
}
func main() {
	fmt.Println("Количество деревьев:", countTrees(2))
	fmt.Println("Количество деревьев:", countTrees(3))
}
```
{% endraw %}

**Вывод:**

```text
Количество деревьев: 2
Количество деревьев: 5
```

## Временная сложность

В оригинале приведены экспоненциальные оценки $$O(n \cdot 2^n)$$ и $$O(4^n / \sqrt{n})$$ со ссылкой на числа Каталана. Рекурсивная версия повторно решает одни и те же подзадачи и также работает за экспоненциальное время. Эти оценки в источнике перенесены из задачи построения деревьев и не являются точными оценками числа вызовов данной функции.

## Пространственная сложность

Оригинал приводит экспоненциальные оценки $$O(2^n)$$ и $$O(4^n / \sqrt{n})$$. Однако показанная функция не строит списки деревьев: она хранит только счётчики и стек рекурсии глубиной до $$n$$. Для этой реализации дополнительная память — $$O(n)$$.

## Версия с мемоизацией

Рекурсивные вызовы многократно вычисляют количество деревьев для одного и того же размера. Сохраним ответы в хеш-таблице `cache`.

В начале вызова проверяем таблицу. Если ответ для `n` уже есть, сразу возвращаем его. Иначе считаем результат, записываем его в `cache` и возвращаем.

{% raw %}
```go
package main

import "fmt"

func countTrees(n int) int {
	return countTreesRec(make(map[int]int), n)
}
func countTreesRec(cache map[int]int, n int) int {
	if count, ok := cache[n]; ok {
		return count
	}
	if n <= 1 {
		return 1
	}
	count := 0
	for i := 1; i <= n; i++ {
		countOfLeftSubtrees := countTreesRec(cache, i-1)
		countOfRightSubtrees := countTreesRec(cache, n-i)
		count += countOfLeftSubtrees * countOfRightSubtrees
	}
	cache[n] = count
	return count
}
func main() {
	fmt.Println("Количество деревьев:", countTrees(2))
	fmt.Println("Количество деревьев:", countTrees(3))
}
```
{% endraw %}

**Вывод:**

```text
Количество деревьев: 2
Количество деревьев: 5
```

### Временная сложность

Для каждого размера от `1` до `n` подзадача вычисляется только один раз. Внутри перебираем все возможные корни, поэтому общая временная сложность — $$O(n^2)$$.

### Пространственная сложность

Хеш-таблица хранит $$O(n)$$ ответов. С учётом стека рекурсии пространственная сложность — $$O(n)$$.

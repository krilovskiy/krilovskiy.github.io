## Условие задачи

Каждое неотрицательное целое число имеет двоичное представление. Например, `8` записывается как `1000`, а `7` — как `0111`, если использовать четыре разряда.

Побитовое дополнение получается заменой каждой единицы на ноль и каждого нуля на единицу. Например, дополнение `1010` — `0101`.

Дано положительное число $$N$$ в десятичной системе. Верните его побитовое дополнение как десятичное целое число. Инвертировать нужно биты двоичной записи без ведущих нулей.

**Пример 1:**

```text
Вход: 8
Выход: 7
```

Двоичная запись `8` — `1000`. Её дополнение — `0111`, то есть `7` в десятичной системе.

**Пример 2:**

```text
Вход: 10
Выход: 5
```

Двоичная запись `10` — `1010`. Её дополнение — `0101`, то есть `5` в десятичной системе.

## Решение

Вспомним свойства XOR:

1. XOR разных битов равен единице: `1 ^ 0 = 0 ^ 1 = 1`.
2. XOR одинаковых битов равен нулю: `0 ^ 0 = 1 ^ 1 = 0`.
3. XOR числа с нулём равен самому числу.

Из первого свойства следует: XOR числа с его дополнением даёт число, все биты которого равны единице. Например:

```text
101 ^ 010 = 111
```

Обозначим эту маску как `all_bits_set`:

```text
number ^ complement = all_bits_set
```

Применим XOR с `number` к обеим частям равенства:

```text
number ^ number ^ complement = number ^ all_bits_set
```

Одинаковые числа обнуляются, а XOR с нулём не меняет число:

```text
0 ^ complement = number ^ all_bits_set
complement = number ^ all_bits_set
```

Остаётся построить `all_bits_set`. Сначала считаем число битов `bitCount` в двоичной записи исходного числа, сдвигая его вправо до нуля. Затем используем формулу:

$$all\_bits\_set = 2^{bitCount} - 1$$

Число $$2^{bitCount}$$ содержит одну единицу и `bitCount` нулей справа. После вычитания единицы получаем `bitCount` младших битов, равных единице. Например, `4` — это `100`, а `4 - 1 = 3` — это `11`.

## Код

По условию `num` положителен. Степень двойки вычисляем сдвигом беззнакового целого, а готовую маску преобразуем в `int`.

{% raw %}
```go
package main

import "fmt"

func bitwiseComplement(num int) int {
	bitCount := 0
	n := num
	for n > 0 {
		bitCount++
		n >>= 1
	}

	all_bits_set := int((uint(1) << bitCount) - 1)
	return num ^ all_bits_set
}

func main() {
	fmt.Println("Побитовое дополнение:", bitwiseComplement(8))
	fmt.Println("Побитовое дополнение:", bitwiseComplement(10))
}
```
{% endraw %}

**Вывод:**

```text
Побитовое дополнение: 7
Побитовое дополнение: 5
```

## Временная сложность

Временная сложность — $$O(b)$$, где $$b$$ — число битов, необходимых для записи исходного числа.

## Пространственная сложность

Алгоритм использует постоянную дополнительную память — $$O(1)$$.

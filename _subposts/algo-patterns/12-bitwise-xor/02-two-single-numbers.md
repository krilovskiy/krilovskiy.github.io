## Условие задачи

Дан непустой массив чисел. Каждое число встречается ровно дважды, кроме двух различных чисел, которые встречаются один раз. Найдите эти два числа.

**Пример 1:**

```text
Вход: [1, 4, 2, 1, 3, 5, 6, 2, 3, 5]
Выход: [4, 6]
```

**Пример 2:**

```text
Вход: [2, 1, 3, 2]
Выход: [1, 3]
```

## Решение

Задача похожа на поиск единственного числа, но теперь чисел без пары два. Обозначим их `num1` и `num2`.

Если вычислить XOR всех элементов массива, повторяющиеся числа обнулят друг друга. Останется `num1 ^ num2`. Назовём этот результат `n1xn2`.

Поскольку `num1` и `num2` различны, хотя бы один их бит отличается. На этой позиции бит `n1xn2` равен `1`, ведь `1 ^ 0 = 0 ^ 1 = 1`.

Выберем любой установленный бит `n1xn2` и разделим по нему все числа массива на две группы: с нулём на этой позиции и с единицей. Тогда `num1` и `num2` попадут в разные группы. Одинаковые числа попадут в одну группу и обнулят друг друга при вычислении XOR внутри неё. В каждой группе останется одно искомое число.

Алгоритм состоит из трёх шагов:

1. Вычисляем XOR всех чисел массива — `n1xn2`.
2. Находим крайний справа установленный бит `n1xn2`. Начинаем с маски `rightmostSetBit = 1` и сдвигаем её влево, пока `rightmostSetBit & n1xn2` равен нулю.
3. Ещё раз перебираем массив. Если `num & rightmostSetBit` не равен нулю, включаем число в XOR первой группы, иначе — второй. Возвращаем оба результата.

## Код

Группы не нужно хранить отдельно: достаточно двух накопителей XOR. Порядок возвращаемых чисел может отличаться от порядка в примере.

{% raw %}
```go
package main

import "fmt"

func findSingleNumbers(nums []int) []int {
	n1xn2 := 0
	for _, num := range nums {
		n1xn2 ^= num
	}

	rightmostSetBit := 1
	for rightmostSetBit&n1xn2 == 0 {
		rightmostSetBit <<= 1
	}

	num1, num2 := 0, 0
	for _, num := range nums {
		if num&rightmostSetBit != 0 {
			num1 ^= num
		} else {
			num2 ^= num
		}
	}
	return []int{num1, num2}
}

func main() {
	fmt.Println("Числа без пары:", findSingleNumbers([]int{1, 4, 2, 1, 3, 5, 6, 2, 3, 5}))
	fmt.Println("Числа без пары:", findSingleNumbers([]int{2, 1, 3, 2}))
}
```
{% endraw %}

**Вывод:**

```text
Числа без пары: [6 4]
Числа без пары: [3 1]
```

## Временная сложность

Два прохода по массиву требуют $$O(N)$$ времени, где $$N$$ — число элементов. Поиск установленного бита ограничен разрядностью целого числа.

## Пространственная сложность

Алгоритм использует постоянную дополнительную память — $$O(1)$$.
